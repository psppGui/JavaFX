# JavaFX Game Development

Estudos sobre desenvolvimento de jogos utilizando Java.

## Tecnologias

- Java
- AWT
- Swing

## Conteúdo

- JFrame
- Canvas
- Game Loop
- Threads
- BufferStrategy
- Renderização 2D

## Executar

```bash
javac Game.java
java Game
```
